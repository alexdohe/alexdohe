## ⚙️ How I work

- A set of agent desks, each with its own rulebook, sharing state through Git rather than chat memory
- Every decision logged in my own words. Anything irreversible or outbound waits for my yes
- On Datestone, council licensing answers are drafted by one model and confirmed by another before they count
- An outside model reviews the whole setup

> **What I've learned:** the worst failures aren't agents forgetting. They're agents saying something is done or checked when it isn't. Most of my rules exist to catch that.
