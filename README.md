# Alex Doherty

Steadicam and broadcast camera operator for 25 years, mostly live sport. For the last 18 months I've also built and run software products without writing the code by hand. I direct AI agents and check their work.

## What I've built
- **Datestone** (datestone.io): landlord compliance for England. Around 34 legal duties, licensing rules for 296 councils, a free check and reminders.
- **The Short Film Show** (theshortfilmshow.com): a curated short-film streaming platform with submissions, a channel and a newsletter.

## How I work
- A set of agent desks, each with its own rulebook, sharing state through Git rather than chat memory
- Every decision logged in my own words. Anything irreversible or outbound waits for my yes
- On Datestone, council licensing answers are drafted by one model and confirmed by another before they count
- An outside model reviews the whole setup

## What I've learned
The worst failures aren't agents forgetting. They're agents saying something is done or checked when it isn't. Most of my rules exist to catch that.
